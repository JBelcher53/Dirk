# Winning Time
 
An NBA analytics metric identifying the point in a game where the outcome becomes mathematically locked in, before the final score makes it obvious.
 
Built as part of a summer research fellowship under Prof. Aaron Williams at Williams College. Presented at a poster session in August 2026.
 
**Validated so far:**
- R² = 0.924 predicting 2025-2026 regular season win totals, outperforming raw point differential (R² = 0.920)
- Cross-season validation: the top-ranked team by Winning Time reached the Finals across multiple consecutive seasons
This project is under active development. Full code and writeup will be published here as the research is extended and submitted for further review.
